NOVA HOME — Smart Home Control App
Task 9 · UI/UX Design · Mobile App
A futuristic smart home interface that helps users monitor connected devices, control their home, and organize devices by room. NOVA HOME combines a dark visual theme with clear device states and familiar controls.
Design Link
View the Figma design
Project Goal
Design an intuitive experience for everyday smart home management. Users should be able to find their devices quickly, understand their current status, and access room controls and common home settings.
Screens
#	Screen	Purpose
01	Home	Home overview, quick scenes, and favorite devices.
02	Rooms	Devices organized into Living Room, Bedroom, Kitchen, and Entryway.
03	Living Room	Room comfort information, device cards, and a room scene.
04	Light Control	Power control, brightness, and color temperature preferences.
05	All Devices	Device list with search, status filters, and an offline recovery prompt.
06	Home Settings	Eco mode, notifications, away mode, connectivity, household members, and security.


Key Features
- Overview of connected devices and room conditions.
- Clear On, Off, and Disconnected device states.
- Device controls represented by switches, sliders, and temperature presets.
- Room-based organization for easier browsing.
- Quick scenes such as Good Morning, Away, and Movie Night.
- Common home preferences and management options.
- Consistent bottom navigation across all six screens.
Device States
State	Visual Treatment	Meaning
On	Mint indicator, “On” label, and active switch	Device is powered on.
Off	Muted indicator, “Off” label, and inactive switch	Device is powered off.
Disconnected	Amber warning and explicit offline label	Device needs connection troubleshooting.


State labels accompany color indicators so users can understand device status without relying on color alone.
